# Rahul Putaka — Portfolio

A responsive personal portfolio built from the information in Rahul Putaka's CV.

## Open in VS Code
1. Open this `rahul-portfolio` folder in VS Code.
2. Open `index.html`.
3. Use **Live Server** (recommended) or open the HTML file directly in a browser.

## Files
- `index.html` — portfolio structure/content
- `css/style.css` — purple-gloss visual design and responsive layout
- `js/script.js` — mobile navigation interaction

The portfolio uses Google Fonts (Manrope and DM Sans), so an internet connection is useful for the fonts. All CV links and contact details are taken directly from the supplied CV.
